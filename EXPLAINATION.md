# Project Architecture & Technical Explanation: Molecular VAE for Drug Discovery

## 1. Executive Summary

This project implements an end-to-end deep generative pipeline for de novo molecular design. By formulating chemical synthesis as sequence generation over character-level SMILES (Simplified Molecular Input Line Entry System) strings, the system trains a **Variational Autoencoder (VAE)** with Recurrent Neural Network (GRU) components on the benchmark ZINC-250k chemical library.

The objective is to map discrete, non-differentiable molecular structures into a continuous 64-dimensional latent space $\mathcal{Z}$, regularized such that novel, biologically relevant chemical structures can be generated by sampling from a prior distribution $p(z) \sim \mathcal{N}(0, I)$.

## 3. Mathematical & Theoretical Framework

### 3.1 Molecular Representation (SMILES Grammar)
Molecules are expressed as ASCII strings using SMILES notation (e.g., `CC(=O)Oc1ccccc1C(=O)O` for Aspirin). The vocabulary comprises atom tokens, bond indicators (`=`, `#`), branching parentheses (`(`, `)`), cycle closure digits (`1`, `2`), and special sequence tokens:
* `<PAD>` (Index 0): Uniform sequence padding to fixed maximum length (122 characters).
* `<SOS>` (Index 1): Start-of-sequence delimiter initiating decoder generation.
* `<EOS>` (Index 2): End-of-sequence delimiter signaling structural termination.

### 3.2 The Variational Autoencoder Formulation
The model defines an encoder recognition network $q_\phi(z|x)$ and a decoder generative network $p_\theta(x|z)$.

1. **Reparameterization Trick**:
   To allow end-to-end backpropagation through stochastic sampling:
   $$\mu = W_\mu h_{enc} + b_\mu, \quad \log \sigma^2 = W_\sigma h_{enc} + b_\sigma$$
   $$z = \mu + \epsilon \odot \exp\left(\frac{1}{2}\log \sigma^2\right), \quad \epsilon \sim \mathcal{N}(0, I_d)$$
   where $d = 64$ is the latent dimension.

2. **Decoupled Autoregressive Decoding**:
   The latent sample $z$ is linearly mapped to initialize the decoder GRU's hidden state:
   $$h_0^{dec} = W_z z + b_z$$
   During training, teacher forcing supplies ground-truth shifted inputs $x_{<t}$. At inference, generation proceeds autoregressively from `<SOS>`.

3. **Loss Function**:
   $$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{recon}} + \beta \cdot \mathcal{L}_{\text{KLD}}$$
   * **Reconstruction Loss ($\mathcal{L}_{\text{recon}}$)**: Multi-class cross-entropy across all sequence positions:
     $$\mathcal{L}_{\text{recon}} = -\frac{1}{T} \sum_{t=1}^{T} \log p_\theta(x_t \mid x_{<t}, z)$$
   * **Kullback-Leibler Divergence ($\mathcal{L}_{\text{KLD}}$)**: Regularizes the approximate posterior against standard Gaussian prior:
     $$\mathcal{L}_{\text{KLD}} = -\frac{1}{2} \sum_{j=1}^{d} \left( 1 + \log(\sigma_j^2) - \mu_j^2 - \sigma_j^2 \right)$$
   * **$\beta$-Scaling factor**: Set to $\beta = 0.05$ to prevent posterior collapse (where decoder ignores latent vector $z$ and relies solely on autoregressive priors).

4. **Temperature-Controlled Generation**:
   During inference, random latent vectors $z \sim \mathcal{N}(0, I)$ generate probability distributions scaled by temperature $T$:
   $$P(w_i) = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$$
   Lower temperatures enforce conservative, highly valid chemistry; higher temperatures promote exploration and diversity.

## 4. Cheminformatics Evaluation Framework

Generated strings are parsed into molecular graph objects via **RDKit**. Evaluation focuses on four core metrics:

1. **Chemical Validity**:
   $$\text{Validity} = \frac{N_{\text{valid}}}{N_{\text{sampled}}} \times 100\%$$
   A SMILES string is valid if and only if RDKit can sanitize the molecular graph (valid valence rules, bond aromaticity, ring closures).
2. **Uniqueness**:
   $$\text{Uniqueness} = \frac{|\text{Unique}(M_{\text{valid}})|}{N_{\text{valid}}} \times 100\%$$
   Measures mode collapse prevention and structural diversity.
3. **Novelty**:
   $$\text{Novelty} = \frac{|\{m \in M_{\text{valid}} : m \notin \mathcal{D}_{\text{train}}\}|}{|\text{Unique}(M_{\text{valid}})|} \times 100\%$$
   Confirms genuine de novo drug hallucination versus memorization.
4. **Physicochemical Druglikeness**:
   * **QED (Quantitative Estimate of Drug-likeness)**: Scored between 0 (non-drug) and 1 (ideal drug profile) integrating Lipinski parameters.
   * **Crippen Wildman LogP**: Octanol-water partition coefficient reflecting lipophilicity.

## 6. Notebook Pipeline Workflow

1. **`01_data_exploration.ipynb`**:
   Loads the ZINC 250k dataset (`250k_rndm_zinc_drugs_clean_3.csv`). Computes baseline metrics using RDKit: molecular weight, LogP, topological polar surface area (TPSA), and hydrogen donor/acceptor counts.

2. **`02_preprocessing.ipynb`**:
   Sanitizes strings, extracts the unique character vocabulary, injects `<PAD>`, `<SOS>`, `<EOS>`, and maps strings to numerical tensors. Saves serialized arrays `X_train.npy` (90%) and `X_test.npy` (10%) along with `vocab.json`.

3. **`03_model_training.ipynb`**:
   Initializes `MolecularVAE` (Embedding: 128, Hidden: 256, Latent: 64). Optimizes parameters using Adam (`lr=0.001`) over 10 epochs with automatic checkpoint resumption. Computes and plots combined reconstruction and KL loss.

4. **`04_generation_evaluation.ipynb`**:
   Draws random latent vectors $z \sim \mathcal{N}(0, I)$, processes tokens through the generative decoder, and runs validity checks through RDKit. Computes preliminary QED score distributions.

5. **`05_visualization.ipynb`**:
   Encodes test set molecules into latent vectors $\mu$. Reduces 64-dimensional embeddings via PCA and t-SNE to inspect smooth transition properties across chemical structural clusters.

6. **`06_deep_evaluation.ipynb`**:
   Scales de novo generation to 100,000 samples. Evaluates full dataset validity (81.31%), uniqueness (99.95%), and novelty (100.00%). Calculates LogP, QED, and generates export-ready tabular datasets and PDF documentation.
